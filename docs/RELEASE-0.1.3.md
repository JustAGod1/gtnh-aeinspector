# AE Inspector 0.1.3 — интерфейс, плавные графики и отдельный GUI Scale

Графики занимают основную часть окна. Список ресурсов стал компактнее: подсветка выбранных строк, средние скорости в минуту, полоски количества за период и отдельная кнопка I/O. Точные количества показываются при наведении. Кнопки и цвета заменены, подписи осей адаптируются к высоте графика. Вверху графиков видны названия выбранных ресурсов; наведение показывает перекрестие, время и данные корзины.

График плавно сдвигается влево между полученными снимками. Левая часть предыдущей истории сохраняется на время анимации, вертикальный масштаб тоже меняется плавно. Отсутствие наблюдений остаётся разрывом. Анимация использует подтверждённые серверные тики, не предсказывает будущий поток и не меняет записанные количества. При остановке поступления данных движение останавливается.

При смене периода, сортировки, выбора ресурса или позиции списка появляется индикатор обновления. До ответа соответствующие элементы управления блокируются. Пакеты несут номер запроса: устаревший ответ не применяет старый фильтр. Сервер обрабатывает явный запрос в ближайшем обновлении контейнера; обычное обновление остаётся раз в секунду. Поиск отправляется после короткой паузы в наборе. При долгом ожидании появляется кнопка повтора; закрытие окна и возврат доступны всегда.

Стрелки страниц убраны. Колесо прокручивает строки, ползунок справа позволяет выбрать произвольную позицию. При перетаскивании показан диапазон строк; запрос отправляется при отпускании ползунка.

## Масштаб окна

Кнопка **Масштаб / Scale** справа от поиска циклически выбирает настройку игры, 1×, 2× и остальные допустимые для текущего разрешения масштабы. Это отдельная проекция окна: общая настройка Minecraft не меняется. Режим учитывает Unicode-шрифт и размер экрана; действует и в I/O. Выбор сохраняется на клиенте в стандартном Forge-конфиге `config/aeinspector-client.cfg`, параметр `client.guiScale` (0 — следовать игре). Статистика по-прежнему сохраняется в NBT мира.

## Установка и ручная проверка

Замените старый JAR на **AE-Inspector-0.1.3.jar** на клиенте и сервере и перезапустите их. Обновление обеих сторон обязательно: изменился формат запросов интерфейса. История, предмет, заряд и привязка сохраняются.

1. Откройте Inspector в работающей сети, выберите ресурс и период 5 секунд. Через два обновления проверьте движение графика влево, подсказки и читаемость осей.
2. Несколько раз быстро нажмите разные периоды. Пока запрос выполняется, кнопки должны быть недоступны; после ответа должен отображаться выбранный период без последующего перебора старых фильтров.
3. Проверьте колесо и перетаскивание ползунка, поиск, выбор нескольких ресурсов через Shift и переход в I/O с подсветкой блока.
4. Переключите масштаб, в том числе во время ожидания ответа. Проверьте попадание мыши по строкам, кнопкам и графику. Измените размер окна Minecraft, закройте Inspector и откройте обычный инвентарь: масштаб остальных окон должен остаться прежним.
5. Откройте Inspector повторно и после перезапуска клиента: его собственный масштаб должен сохраниться.

## Проверка сборки

`test reobfJar`: 49 автоматических тестов, без ошибок. Новые проверки покрывают номера запросов и устаревшие ответы, блокировку при задержке, непрерывность движения графика, сохранение левого края при частых ответах, разрывы наблюдений, границы скролла, размещение элементов на доступных высотах и вычисление локального GUI Scale. Существующие проверки учёта, NBT и зарядки также проходят.

Эти проверки не заменяют визуальную проверку в GTNH: Minecraft для этой версии не запускался. Игровую проверку выполняет пользователь. Собственные потоки не добавлены; нагрузочные замеры не выполнялись.
