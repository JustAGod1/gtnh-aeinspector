# AE Inspector 0.1.9 — Storage Bus в I/O

Исправлены два пути обнаружения Storage Bus в списке устройств.

## Каталог подключённых устройств

Предметные и жидкостные Storage Bus добавлены в каталог загруженных узлов. Шина попадает в I/O, если ресурс есть в её подключённом хранилище, соответствует настроенному положительному фильтру или уже имеет исторические передачи. Пустой фильтр сам по себе не добавляет все шины к каждому ресурсу; чёрный список не считается положительным назначением ресурса. История не скрывается при опустошении хранилища.

Фильтры проверяются через готовый фильтр AE, включая правила fuzzy/Ore. Для кастомных мониторов наличие ресурса читается из уже собранного снимка — дополнительные зрители не вызывают повторный полный опрос такого хранилища. Для штатного адаптера используется чтение количества одного ресурса. Проверка не вызывает insert/extract, включая симуляции. Сам обработчик читается из уже подключённой шины, без вызова перестройки Storage Bus или загрузки соседнего чанка.

В подсказках отдельно показываются совпадение фильтра и наличие ресурса в хранилище. Активность Storage Bus теперь определяется по его узлу, а не всегда отображается как неактивная. Координаты и подсветка используют существующие идентификаторы устройств.

## Обновление индекса истории

Индекс предполагал, что предшествующие сегменты больше не получают новые пары «ресурс–устройство». Если такой сегмент возобновлял работу, уже известный суммарный ряд получал новые количества, но новое устройство не попадало в кеш I/O. Это воспроизведено отдельным тестом: график содержал приход 2005, а поиск устройства возвращал отсутствие строки.

Теперь создание новой пары уведомляет существующие индексы. Они дочитывают только новые пары относящихся к ним сегментов, по одному шагу в существующей очереди запросов. Повторного обхода всех предшествующих сетей нет. Уже индексированные пары не добавляются дважды; посторонние сети не вызывают обновление этого индекса. Подписки слабые, чтобы мир не удерживал вытесненные индексы. Существующие количества, NBT и время статистики не менялись; новых потоков нет.

## Проверки и установка

`test reobfJar`: **86 тестов без ошибок**. Проверены чтение наличия ресурса без передач, фильтры, оба вида Storage Bus в каталоге, доступ к обработчику закреплённых AE2/AE2FC, историческая строка после загрузки NBT, новые пары в возобновлённом предшествующем сегменте и отсутствие повторного обхода истории. Регрессионный тест кеша падал до исправления и проходит после него.

На копии пользовательского сохранения запрос I/O для Glowflower вернул Stocking Input Bus и ME Storage Bus в координатах `−8, 66, 88`, включая оценочный приход 2005. Это подтверждает сохранность записи; само исчезновение строки в работающем GUI на копии не воспроизводилось. Игра не запускалась, файл мира не изменялся. Новое отображение и применение изменённого Mixin требуют ручной проверки.

Замените предыдущий JAR на **AE-Inspector-0.1.9.jar** на клиенте и сервере и перезапустите игру. Откройте I/O у Glowflower: проверьте строку Storage Bus, координаты, скорость и подсветку по клику. При остановке автоматики шина с запасом ресурса должна оставаться в списке. Графики сохранены в единицах за секунду; списки — за минуту. Высота списка по-прежнему меняется перетаскиванием разделителя.
