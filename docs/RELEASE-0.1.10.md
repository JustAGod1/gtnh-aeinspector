# AE Inspector 0.1.10 — исправление Mixin Storage Bus

Исправлена ошибка 0.1.9, из-за которой открытие инспектора завершалось `ClassCastException: PartStorageBus cannot be cast to StorageBusAccess` и сообщением `Could not read history`.

В полном логе перед этой ошибкой обнаружен отказ Mixin: `Found a remappable @Shadow annotation on handler`. Перехват применяется сразу к предметной и жидкостной Storage Bus. Для такого Mixin загрузчик требует явный `@Shadow(remap = false)` на поле; настройки `remap = false` на самом классе недостаточно. Из-за пропущенного параметра загрузчик отвергал весь перехват, включая интерфейс доступа к обработчику. Параметр исправлен.

Регрессионная проверка байткода проверяет это ограничение для всех многоклассовых перехватов мода. Она падала на `StorageBusAttachmentMixin.handler` до исправления. Тестовый игровой smoke-harness также дополнен проверкой интерфейса и метода доступа на обоих видах Storage Bus, но в этой проверке игра не запускалась.

`test reobfJar`: 87 тестов, без ошибок. Это проверка сборки и регрессий без запуска Minecraft; применение Mixin в полном GTNH и открытие I/O нужно проверить в игре. Протокол GUI, формат NBT, расчёты и потоки исполнения не менялись.

## Установка

Замените старый JAR на `AE-Inspector-0.1.10.jar` и полностью перезапустите процесс Minecraft/сервера. Выхода из мира недостаточно: Mixin применяется при загрузке классов.

В одиночной игре встроенный сервер работает внутри клиента, поэтому обновляется JAR в клиентском инстансе. На выделенном сервере этот фикс требуется серверу; формат пакетов клиентов 0.1.7–0.1.9 не изменён. Для одинакового набора клиентских возможностей можно поставить 0.1.10 на обе стороны.

Откройте инспектор, затем I/O у Glowflower: проверьте строку Storage Bus и подсветку по клику. Сохранённая история не требует удаления или конвертации.
