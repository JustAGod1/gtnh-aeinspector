# AE Inspector 0.1.4 — исправление тяжёлых запросов GUI

При открытом Inspector сервер мог надолго останавливаться в `InspectorData.build → HistoryQuery`. Старый код заново обходил историю сети для каждого ресурса, создавал полные графики для сортировки и выполнял весь запрос в одном тике. После закрытия окна этот расчёт прекращался — дополнительной утечки открытого контейнера в проверке не обнаружено.

## Что изменилось

- История сети индексируется один раз: ресурс и устройство сопоставляются только с сегментами, содержащими их данные. Общие предки учитываются однократно. В памяти кешируются индексы четырёх сетей; новые пары текущей сети добавляются постепенно.
- Покрытие наблюдений объединяется один раз на ответ. Средние скорости используют общий индекс интервалов, без повторного копирования и сортировки покрытия для каждого предмета.
- Список читает только количества. Массивы графиков выделяются только для выбранных ресурсов. Сравнение строк при сортировке использует уже вычисленные количества, а сортировка выполняется по частям.
- Поиск, обход фильтров, подготовка строк и графиков разбиты на небольшие шаги. Общая очередь всех зрителей обрабатывается в существующем серверном потоке с мягким бюджетом **2 мс на тик**, с чередованием зрителей.
- Основной экран не рассчитывает список I/O. Экран I/O не рассчитывает основную таблицу и её графики.
- Закрытие контейнера и новый запрос отменяют незавершённую работу. Повтор того же запроса не сбрасывает её прогресс. При изменении сети запрос перезапускается для актуальной топологии. Без открытых запросов очередь ничего не рассчитывает.
- Названия ресурсов кешируются по точному числовому ID; идентичность metadata/NBT не изменена.

Бюджет кооперативный: новый шаг не начинается после его исчерпания. Уже начавшийся вызов API другого мода, вычисление названия с большим NBT, сборка мусора или сжатие готового пакета могут выйти за этот бюджет. Это не гарантия максимального времени любого игрового тика.

При первом открытии большой сети построение индекса может занять несколько тиков; показывается существующий индикатор загрузки. Следующие запросы используют кеш. Один ресурс фиксируется при начале его чтения: данные текущего сегмента копируются сразу, завершённые предки дочитываются порциями. Разные ресурсы одного ответа могут быть сняты в разные серверные тики; каждый график сохраняет собственные временные координаты. Накопленные количества на сервере не округляются и не пропускаются.

## Проверено

- `test reobfJar`: **57 тестов**, без ошибок. Проверены суммы, графики и покрытие для всех девяти масштабов, общие предки, глубокая история, новые пары в кеше, передачи после начала чтения, общий бюджет нескольких зрителей, отмена и завершение задач.
- Проверка на копии пользовательского `aeinspector.dat`: 68 929 сегментов в мире; выбранная цепочка содержит 33 832 сегмента и 234 исторических ресурса. Новый алгоритм обработал их итоги; 54 сравнения графиков с прежним алгоритмом (6 ресурсов × 9 масштабов) совпали по каналам, итогам и наблюдениям.
- Проверка читала только копию истории и не запускала Minecraft. Файл мира не изменялся. Утилита воспроизведения не входит в устанавливаемый JAR.

Сам исправленный JAR ещё требует ручной проверки в GTNH. Замеры времени тиков новой версии в игре не выполнены. Сохранение всей истории в NBT в этой версии не менялось и может отдельно влиять на время автосохранения.

## Установка и проверка

Закройте клиент и сервер, замените старый JAR на **AE-Inspector-0.1.4.jar** на обеих сторонах и запустите снова. Формат GUI-запроса дополнен признаком экрана I/O; смешивать версии нельзя.

Откройте Inspector на большой сети, дождитесь первого ответа, смените период, прокрутите список и откройте I/O. Проверьте отсутствие прежних многосекундных остановок, а также закрытие окна во время загрузки. Масштаб, оформление, подсветка, зарядка и сохранение в NBT остаются доступными. Дополнительных потоков мод не создаёт.

Для повторной проверки копии истории из исходников:

```powershell
.\gradlew.bat verifySavedHistory -PhistoryFile=C:/path/to/copied-aeinspector.dat --console plain
```
