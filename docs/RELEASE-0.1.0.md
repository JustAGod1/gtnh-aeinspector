# AE Inspector 0.1.0

Первая публичная версия для GTNH 2.8.4 / Minecraft 1.7.10.

## Установка

1. Полностью закройте Minecraft. Для выделенного сервера остановите сервер.
2. Уберите предыдущий JAR AE Inspector из папки `mods`.
3. Поместите `AE-Inspector-0.1.0.jar` в `mods` клиента и сервера. В одиночной игре достаточно установки в клиент.
4. Запустите игру. Существующий Inspector, его заряд и привязка сохраняются.

Требуются AE2 `rv3-beta-695-GTNH`, AE2FC `1.4.120-gtnh` и UniMixins из сборки GTNH 2.8.4. Прямой зависимости от GregTech нет. Собственных фоновых потоков мод не создаёт.

## Использование

Рецепт: беспроводной терминал AE + calculation processor. Заряд и привязка терминала переносятся. Предмет можно также получить командой `/give @p aeinspector:inspector 1`, зарядить и привязать через терминал безопасности ME.

ПКМ заряженным привязанным Inspector в радиусе wireless access point открывает статистику.

- Два графика: приход в ME и расход из ME; девять временных масштабов.
- Список ресурсов: количество за выбранный период, средняя скорость в минуту и полоски. Жидкости измеряются в mB.
- Поиск; сортировка по приходу, расходу или имени.
- Клик по ресурсу выбирает его график; Shift + клик позволяет сравнить до восьми ресурсов.
- Кнопка **I/O** в строке ресурса открывает отдельное окно устройств. «В ME» — поставщики, «Из ME» — потребители. Наведение показывает количества, оценки и координаты; клик подсвечивает известное устройство в мире.
- «Назад» или Esc в окне I/O возвращает к статистике.

Количество относится к выбранному периоду; скорость усредняется по наблюдавшимся серверным тикам. Например, 94 000 предметов за 10 минут непрерывного наблюдения — 9 400 шт./мин. Время выгрузки сети не подменяется нулевым потоком.

## Изменения относительно тестовых сборок

Исправлены мгновенное закрытие GUI после ПКМ, состояние OpenGL после рисования иконок и определение координат import/export bus. Добавлены отдельный экран I/O, сортировка, скорости в минуту и причины закрытия GUI в чате. Предметы различаются по registry ID, metadata и полному NBT; при подготовке Fluid Drop для сопоставления фильтров сохраняется тег жидкости.

## Статус проверки

Релиз содержит текущую реализацию, а не подтверждение выполнения всей исходной спецификации. Полная проверка автокрафта, отмены, подсетей, внешних хранилищ, Discretizer и нагрузки в GTNH ещё не завершена. Последняя переработка GUI требует подтверждения в игре; целевая производительность не подтверждена. Нагрузочные измерения отложены по указанию пользователя.

Старые передачи «без определённого устройства» невозможно достоверно распределить между блоками задним числом. Их количества сохраняются, фиктивные координаты не показываются.

История хранится в каталоге `aeinspector` внутри сохранения мира. При сообщении об ошибке укажите версию JAR и приложите `logs/latest.log`.
