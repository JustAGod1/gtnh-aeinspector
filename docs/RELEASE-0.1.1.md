# AE Inspector 0.1.1

Добавлена явная поддержка RF-зарядки через `IEnergyContainerItem`, в том числе для Ender IO Wireless Charger 2.9.28 из GTNH 2.8.4. Inspector больше не полагается на сохранение опционального RF-интерфейса базового класса загрузчиком AE2. RF преобразуется в AE по коэффициентам AE2, не через EU.

Замените старый JAR на `AE-Inspector-0.1.1.jar` на клиенте и сервере после их остановки. Создавать новый Inspector не нужно: заряд и привязка сохраняются.

Для проверки возьмите один частично разряженный Inspector в инвентарь и встаньте в радиусе включённого Wireless Charger с запасом RF. Заряд Inspector должен расти, а RF зарядника расходоваться. Затем проверьте открытие GUI и сохранение привязки. Стопка из нескольких предметов не заряжается самим Ender IO.

Сборка и 33 автоматических теста прошли. Новые тесты проверяют явно объявленный RF-интерфейс, коэффициент RF/AE, отсутствие зарядки при симуляции, частичную передачу, полную батарею, отрицательное предложение и сохранение привязки. Проверка реального зарядника в игре остаётся ручной.

Остальное управление и текущие ограничения: [инструкция 0.1.0](RELEASE-0.1.0.md).
