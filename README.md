# AE Inspector

Мод для **GTNH 2.8.4 / Minecraft 1.7.10**, версия **0.1.0**.

Беспроводной инспектор ME-сети: графики прихода и расхода предметов и жидкостей, средние скорости в минуту, поиск, сортировка и отдельное окно **I/O** со списком устройств и подсветкой в мире.

## Установка и управление

Установите `AE-Inspector-0.1.0.jar` на клиент и сервер, заменив предыдущую версию. Рецепт: беспроводной терминал AE + calculation processor. Заряд и привязка переносятся.

- ПКМ инспектором открывает статистику.
- Клик по ресурсу выбирает график; Shift + клик добавляет ресурс к сравнению.
- Кнопка **I/O** в строке ресурса открывает его поставщиков и потребителей.
- Клик по устройству включает подсветку AE2.

Подробности и ограничения: [инструкция к версии 0.1.0](docs/RELEASE-0.1.0.md).

## Сборка

Нужен **JDK 25** для запуска Gradle. Gradle Wrapper включён в репозиторий; зависимости скачиваются при первой сборке. Дополнительные Java toolchains разрешаются настройками сборки GTNH.

Windows PowerShell:

```powershell
.\gradlew.bat test reobfJar --console plain
```

Linux/macOS:

```sh
bash ./gradlew test reobfJar --console plain
```

Устанавливаемый файл: `build/libs/AE-Inspector-0.1.0.jar`. Файл с суффиксом `-dev.jar` предназначен для разработки.

Зависимости: AE2 `rv3-beta-695-GTNH`, AE2FC `1.4.120-gtnh`, UniMixins. Прямой зависимости от GregTech нет. Мод не создаёт собственных потоков: учёт и сохранение выполняются в серверном потоке.

## Структура

- `src/main` — мод, Mixins, GUI и локализации.
- `src/test` — автоматические тесты и отдельно запускаемый бенчмарк.
- `src/smoke` — необязательный стенд проверки загрузки Mixins; не входит в релизный JAR.
- `docs` — установка, ручные проверки и результаты проверки.
- `gradle`, `gtnhShared` — файлы сборки и форматирования.

`build`, `dist`, `run`, `.tools` и `.research` — локальные/генерируемые каталоги, исключённые из Git. JAR и архивы исходников следует прикладывать к релизам, а не коммитить.

## Статус

Полная проверка GUI, автокрафта, отмены, подсетей, storage bus и Discretizer в GTNH ещё не завершена. Целевая производительность не подтверждена. Точные metadata/NBT сохраняются; отсутствующий NBT отличается от пустого.
