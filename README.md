# AE Inspector

Мод для **GTNH 2.8.4 / Minecraft 1.7.10**, версия **0.1.11**.

Беспроводной инспектор ME-сети: графики прихода и расхода предметов и жидкостей, средние скорости в минуту, поиск, сортировка и отдельное окно **I/O** со списком устройств и подсветкой в мире.

## Установка и управление

Установите `AE-Inspector-0.1.11.jar` на **клиент и сервер**: в этой версии изменён протокол запросов GUI. Для одиночной игры замените JAR в своём инстансе и полностью перезапустите Minecraft. Рецепт: беспроводной терминал AE + calculation processor. Заряд и привязка переносятся. Поддерживается RF-зарядка, включая Ender IO Wireless Charger. Историю сохраняет Minecraft в NBT мира. [Состояние GUI и возврат из I/O 0.1.11](docs/RELEASE-0.1.11.md) · [Исправление запуска перехвата Storage Bus 0.1.10](docs/RELEASE-0.1.10.md) · [Storage Bus в I/O 0.1.9](docs/RELEASE-0.1.9.md) · [Единицы графиков 0.1.8](docs/RELEASE-0.1.8.md) · [Storage Bus и размер списка 0.1.7](docs/RELEASE-0.1.7.md) · [Общая шкала графиков 0.1.6](docs/RELEASE-0.1.6.md) · [Прокрутка и фильтры 0.1.5](docs/RELEASE-0.1.5.md) · [Исправление тяжёлых запросов 0.1.4](docs/RELEASE-0.1.4.md) · [Интерфейс и масштаб 0.1.3](docs/RELEASE-0.1.3.md).

- ПКМ инспектором открывает статистику.
- Клик по ресурсу выбирает график; Shift + клик добавляет ресурс к сравнению.
- Кнопка **I/O** в строке ресурса открывает его поставщиков и потребителей.
- Из I/O можно вернуться кнопкой **Назад**, клавишей **Esc** или боковой кнопкой мыши **Назад**. Основное окно продолжает обновляться во время просмотра устройств; возврат сохраняет графики, выбор ресурсов и прокрутку без нового запроса главного экрана.
- После закрытия инспектора запоминаются период, поиск, сортировка, фильтр, размеры панелей и масштаб. Выбранные ресурсы и прокрутка восстанавливаются при повторном открытии в рамках того же подключения; при переходе в другой мир числовые ID ресурсов не переносятся.
- Storage Bus виден в I/O по историческим передачам, наличию ресурса в подключённом хранилище или совпадению настроенного положительного фильтра. Подсказка различает наличие ресурса и совпадение фильтра.
- Клик по устройству включает подсветку AE2.
- Колесо и увеличенный ползунок прокручивают весь полученный список локально, без запросов к серверу. Строки меняются прямо во время перетаскивания, в том числе в I/O.
- Потяните разделитель над списком вверх, чтобы показать больше строк, или вниз, чтобы увеличить графики. ПКМ по разделителю возвращает обычную высоту. Размер сохраняется на клиенте; изменение высоты не запрашивает данные у сервера.
- Изменения содержимого за Storage Bus учитываются как оценка: увеличение — приход, уменьшение — расход. Кастомные адаптеры наблюдаются через API `IMEMonitor`/`IMEInventory`, без зависимости от конкретного мода хранилища; известные операции AE вычитаются из изменения запаса.
- Кнопка рядом с сортировкой переключает **Все → Предметы → Жидкости**. Фильтр работает вместе с поиском и сортировкой; при переключении выбирается первый подходящий ресурс.
- Наведение на график показывает время, скорость и количество в выбранной корзине.
- Графики прихода и расхода используют общую вертикальную шкалу **в секунду**; списки ресурсов и устройств показывают среднее **в минуту**. В режиме 5 с точки показывают отдельные тики: передача порцией создаёт пик; `/с` — единица скорости, а не усреднение за целую секунду.
- **Масштаб** меняет GUI Scale только инспектора: настройка игры → 1× → 2× → доступные масштабы. Выбор сохраняется в клиентском `config/aeinspector-client.cfg`.
- При смене периода/сортировки/фильтра отображается индикатор загрузки; следующий запрос доступен после получения ответа. Прокрутка уже полученных строк, закрытие окна, возврат и локальный масштаб остаются доступны.

Подробности и ограничения: [инструкция к версии 0.1.0](docs/RELEASE-0.1.0.md).

## Сборка

Нужен **JDK 25** для запуска Gradle. Gradle Wrapper включён в репозиторий; зависимости скачиваются при первой сборке. Дополнительные Java toolchains разрешаются настройками сборки GTNH.

Windows PowerShell:

```powershell
.\gradlew.bat test reobfJar --console plain
```

Linux/macOS:

```sh
bash ./gradlew test reobfJar --console plain
```

Устанавливаемый файл: `build/libs/AE-Inspector-0.1.9.jar`. Файл с суффиксом `-dev.jar` предназначен для разработки.

Зависимости: AE2 `rv3-beta-695-GTNH`, AE2FC `1.4.120-gtnh`, UniMixins. Прямой зависимости от GregTech нет. Мод не создаёт собственных потоков: учёт и сохранение выполняются в серверном потоке.

## Структура

- `src/main` — мод, Mixins, GUI и локализации.
- `src/test` — автоматические тесты и отдельно запускаемый бенчмарк.
- `src/smoke` — необязательный стенд проверки загрузки Mixins; не входит в релизный JAR.
- `docs` — установка, ручные проверки и результаты проверки.
- `gradle`, `gtnhShared` — файлы сборки и форматирования.

`build`, `dist`, `run`, `.tools` и `.research` — локальные/генерируемые каталоги, исключённые из Git. JAR и архивы исходников следует прикладывать к релизам, а не коммитить.

## Статус

Полная проверка GUI, автокрафта, отмены, подсетей, storage bus и Discretizer в GTNH ещё не завершена. Целевая производительность не подтверждена. Точные metadata/NBT сохраняются; отсутствующий NBT отличается от пустого.
